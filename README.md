# IBM Applied Data Science Capstone – SpaceX Falcon 9 Landing Prediction

## Project Overview

This repository contains my completed work for the **IBM Applied Data Science Capstone** course.

The objective of this project is to apply the complete data science methodology to analyse historical SpaceX Falcon 9 launch data and build machine learning models capable of predicting whether the first-stage booster will land successfully.

The project covers the full data science lifecycle, including data collection, data wrangling, exploratory data analysis, interactive visualisation, predictive modelling, and presentation of findings.

---

## Project Objectives

* Collect launch data from the SpaceX REST API and Wikipedia.
* Clean and prepare the data for analysis.
* Perform exploratory data analysis (EDA) using Python visualisations and SQL.
* Build interactive maps using Folium.
* Develop an interactive dashboard using Plotly Dash.
* Train and evaluate machine learning classification models.
* Predict Falcon 9 first-stage landing success.

## Machine Learning Models

The following classification algorithms were trained and evaluated:

* Logistic Regression
* Support Vector Machine (SVM)
* Decision Tree
* K-Nearest Neighbours (KNN)

Hyperparameter tuning was performed using **GridSearchCV** with cross-validation to identify the optimal model configuration.

---

## Key Findings

* Falcon 9 landing success rates improved significantly over time.
* Launch site, orbit type, payload mass, and booster version were important predictors of landing success.
* Interactive visualisations provided valuable insight into launch trends and operational performance.
* Machine learning models successfully predicted landing outcomes using historical launch data.
